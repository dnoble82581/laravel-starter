# Livewire/Auth

**What it is**  
Views for authentication‐related Livewire components.

**When to use**  
- For login, registration, password-reset forms built in Livewire.

**Example Files**  
- `login.blade.php` – `wire:model` fields + validation errors.  
- `register.blade.php` – multi-field form for new user signup.

**Usage**
```blade
<livewire:auth.login />
<livewire:auth.register />
